MockServer tool-window icons — three options

DECIDED 2026-09-23 — option B, the knockout badge, was chosen and shipped. The icons live at src/main/resources/icons/mockserver_{dashboard,debugger,llm}.svg (plus _dark variants) and are wired per tool window in plugin.xml. This page is kept as the record of what was compared, not as an open question.

Judge these at the 13 px column. That is the real stripe size; everything larger is only to show construction. A single letter is about all that fits — a word would be unreadable, which is why each option uses one.

A - solid badge

Highest contrast at 13px. The disc covers part of the mark, so the MockServer identity is slightly reduced.
